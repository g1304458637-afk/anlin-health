# 本地展示说明

本轮改动面向毕业设计、比赛答辩与功能演示，使用独立的虚构数据。
本文说明本地展示环境的启动与验证方式；代码同步不代表服务已部署。

## 启动

在仓库根目录使用 Python 3.12。Windows PowerShell 首次运行示例：

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r backend\requirements-dev.txt
.\.venv\Scripts\python.exe backend\scripts\local_preview.py
```

已有可用 Python 环境和依赖时，直接运行：

```powershell
python backend/scripts/local_preview.py
```

启动脚本自动迁移数据库、初始化虚构示例，再监听本机 `127.0.0.1:8765`。
居民/家属入口：<http://127.0.0.1:8765/app>；工作台：<http://127.0.0.1:8765/console>。
接口文档：<http://127.0.0.1:8765/docs>。在终端按 `Ctrl+C` 停止服务。

数据保存在 `backend/.runtime/preview.db`，报告原件保存在 `backend/.runtime/reports/`。
重复启动会保留演示操作，不会恢复成空白数据；重启后需重新登录。
这个入口与 README 中使用 8000 端口的 `dev_start.py` 是两种启动方式。

## 建议演示顺序

1. 使用 `resident` 登录，进入“健康”，切换血压、血糖、体重和 7/30/90 天趋势。
   点击曲线圆点，查看实际测量时间、来源及血糖进餐说明；补录时可填写实际发生时间。
2. 进入“我的健康计划”，创建每日或每周计划，设置当地时间、时区及起止日期。
   查看未来 7 天任务和未完成的逾期事项，演示完成、延后 1 小时、取消单次任务。
   再演示暂停、恢复和结束计划，观察计划状态与单次任务状态分别变化。
3. 从“整理检查报告”进入报告档案，按关键词、状态或日期检索。
   选待核对副本，对照原件确认字段；选已确认报告，填写修改原因并保存新修订。
   展开历史版本，展示确认字段、排除项、修改原因和确认人均有留痕。
4. 切换 `staff` 工作台，演示随访的待完成/已完成/全部筛选和每页 25 条分页。
   首页展示最多 8 条待完成随访；总数来自独立统计，不随列表分页改变。
   为已授权居民录入指标时，同样可以填写实际测量时间。
5. 切换 `family` 或 `admin`，对照不同角色能看到的范围；退出账号后旧数据应清空。

居民端和工作台已使用统一的浅色青绿主题、本地插画与移动端布局。

## 展示边界

- 预置报告和提取字段来自仓库内的虚构样本，**不是实时 AI 提取结果**。
  预置“已确认”状态用于展示流程，不代表真实人工或医学核验。
- `local_preview.py` 清空云端模型密钥并关闭报告提取后台任务。
  本预览不进行真实 AI 调用；新上传报告的实时提取、报告问答与助手不属于本次离线演示。
- 报告修订保留旧版本，不覆盖或重新创建已导入的健康指标。
  来源发生相关修订的指标会显示待核对提示，需要单独检查。
- 周期任务只在站内显示，没有短信、微信或系统通知投递。
  完成操作是用户确认，不会自动执行测量、填写问卷或证明健康任务已实际完成。
- 服务运行时约每分钟生成当前窗口，打开任务列表也会补齐窗口。
  **进程停机过长不会补生成已经过去日期的历史任务**；已有未完成任务仍保留。
- 暂停会取消尚未到期的待办，已逾期任务保留；恢复只恢复仍在未来、因暂停而取消的任务。
  手动取消的单次任务不会随恢复重建；结束计划不可恢复。
- 家属共享不开放周期计划的读写，报告也不随一般测量授权共享。
  预览数据只用于功能展示，不用于诊断、治疗或实际居民服务。
