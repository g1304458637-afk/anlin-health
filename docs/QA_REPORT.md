## 真实 HTTP 本地服务抽检

使用演示数据库启动 `uvicorn` 后，在本地 HTTP 请求验证：社区工作者登录返回 `200`、社区统计为 3 个虚构居民、社区列表只返回本社区居民、跨社区档案读取返回 `404`、为授权的居民新增体重记录返回 `201`。这确认了本地运行的服务能够处理这些典型请求，但**并非完整生产部署或浏览器 E2E**。

## 浏览器 UI 冒烟（模拟数据，不是线上 E2E）

`python backend/scripts/console_ui_smoke.py` 在当前执行环境下使用系统 Chromium 和内存模拟 API，验证后台登录界面、登记居民、录入一条血糖值的交互并成功生成 `assets/管理工作台_静态效果图.png`。这仅验证了客户端组件与 JavaScript 事件，不代表浏览器到真实 API 的端到端测试已经完成。

静态校验还检查了小程序 **11 个 JSON 文件解析成功**、**11 个 JavaScript 文件 `node --check` 语法通过**；微信 WXML/运行时仍需官方开发者工具验收。
