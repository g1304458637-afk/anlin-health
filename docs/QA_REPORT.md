### 新增安全边界 19 项（`tests/test_security.py`）

- `/api/auth/login` 成功登录；连续 5 次失败锁定（正确密码也返回 423），锁过期自动解除并清零计数。
- 登录按账号+IP 速率限制：第 11 次尝试返回 429，正确密码同样被拦。
- 停用账号无法登录（403）。
- 改密策略：弱密码/常见密码/仅两类字符被 422 拒绝；旧密码错误 401；改密成功后旧 JWT 立即 401、新令牌可用、新密码可登录。
- `logout-all` 后原令牌立即失效。
- TOTP：开通返回 secret 与 otpauth:// URI；仅密码登录返回 401 + `X-MFA-Required: totp`；错误验证码 401；正确验证码登录成功；关闭 MFA 后密码直登恢复。TOTP 模块对非法输入拒绝。
- 管理员边界：员工访问 `/api/admin/users` 403；列表不含 `password_hash`/`invite_code`；不能停用自己；停用后目标用户在线令牌立即 401、登录 403；启用后可登录。
- 档案认领：不匹配与匹配请求返回完全一致（防枚举）；仅匹配生成待核验申请；跨社区员工看不到也批不了；批准后申请人立即拥有档案；重复复核 409；已建档用户认领 409；家属角色 403。
- 认领申请每用户每小时 5 次限额（第 6 次 429）。
- 纸质同意复核：协助建档产生 pending 事件入队；跨社区复核 404；驳回后员工立即失去该居民访问、社区列表不再显示；重复复核 409。居民自建同意自动 approved。
- 邀请码轮换：旧码授权 422、新码成功；家属可拒绝（decline）授权并立即失去访问。
- 安全响应头（nosniff/DENY/no-referrer/CSP）与管理台演示提示开关 `/api/auth/demo-status`。
- 手机号加密落库：配置密钥后 API 返回明文、数据库原始值为 `enc:v1:` 密文；无前缀旧值兼容可读。
