# 微信小程序接入与验收手册

## 当前状态

小程序源代码已写，页面共 **8** 个，`wx.login` 已对接后端 `/api/auth/wechat`，后端按微信官方 `jscode2session` 机制交换 OpenID 并建立低权限居民账号。**当前没有真实微信小程序 AppID、AppSecret、合法 HTTPS 域名、微信开发者工具执行结果，所以不能宣称微信登录已联通或小程序真机运行通过。**

## 联调步骤

1. 申请/使用自有微信小程序 AppID，并确认适用类目、主体和所需资质。
2. 后端环境配置 `WECHAT_APPID` 与 `WECHAT_APPSECRET`（仅服务器端），重新启动后端。不要把 AppSecret 放进小程序源码。
3. 在微信开发者工具中导入根目录 `miniapp/`，把 `project.config.json` 中的 `touristappid` 替换成真实 AppID。
4. 开发者工具本机联调可使用 `miniapp/config.js` 中的 `http://127.0.0.1:8000`，暂时关闭本地“校验合法域名”仅用于开发；**真机远端必须使用服务可访问的 HTTPS API 域名**，并在微信后台配置合法 request 域名。
5. 登录页面点击“微信授权登录”，检查 `wx.login` → `/api/auth/wechat` → 微信 `jscode2session` → `/api/me`。
6. 新建居民档案、填血压、完成两个问卷、安排提醒、家属切换角色/邀请码绑定和撤回授权。每条流程要保留小程序真机截图及后端审计日志（注意脱敏）。
7. 逐项测试：无网、超时、断连、微信凭据过期、重复提交、拒绝权限、社区已撤回授权、家属授权到期、背景/前台切换。
8. 必须在实际支持的系统和机型覆盖大字号、对比度、触控范围、虚拟键盘遮挡、历史趋势 canvas 显示。

## 消息提醒

当前 `reminders` 模块是**应用内日程列表，不包括手机推送**。若要实现微信订阅通知，后续需要：选择/审核适用通知模板；在符合规范的交互节点调用 `wx.requestSubscribeMessage` 征求用户许可；后台具备合法调用凭据和可靠调度任务；在发送前再次校验用户授权与订阅状态；失败重试幂等、退订处理、频率和隐私内容限制。订阅消息支持规则随微信官方平台调整，**不能承诺一次授权后永久、无限次推送**。

## 账号与家属身份

首次微信登录只会创建低权限 `resident` 账号，建档后不可再切换成家属角色。未建档账号可以在“家庭共享”页面切换为 `family`，但切换并不自动获取任何居民数据。正式版建议把家庭成员角色设计成可并存而非单角色，以兼容同一人既是居民又是他人家属的场景；当前系统先保证权限简单、可靠。
