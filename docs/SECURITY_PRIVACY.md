# 信息保护与安全评估：v0.6 本地候选

本文件记录已实现的技术边界和真实用户上线前的工作，不构成合规或生产验收结论。当前仅在隔离工作树和虚构数据上验证；不得据此录入真实健康信息。

## 已实现并在本地验证的控制

- 登录有密码强度、账号/IP 限流、失败锁定、停用检查、审计与 `token_version` 会话失效。TOTP 先暂存密钥，验证新认证器验证码后才启用；启用状态下重设/关闭需当前密码和现有验证码。机构账号分发、认证器遗失恢复仍需制度。
- 管理员可为指定社区开通固定 `staff` 角色账号，并查看、停用或启用账号，以安排第二位员工独立复核；网页没有管理员创建、角色编辑或密码重置入口。初始管理员只由受控的空库初始化脚本建立。
- 居民自主建档、家属授权和社区护理同意由服务端对象级权限约束。员工处理个人健康信息需要同社区且最新护理同意有效并已批准。纸质同意由另一位同社区员工复核；待复核与驳回不能授予访问。居民可撤回/重授，家属授权受字段、期限、撤回和拒绝约束。
- 线下档案认领只接受申请，档案号/姓名/电话匹配与否返回统一提示；同社区员工线下核验批准前不授予档案。认领不自动产生社区护理同意。
- 在配置 `FIELD_ENCRYPTION_KEY` 后，居民电话、认领电话、待确认与启用的 TOTP 密钥用 AES-GCM 加密存储；生产启动要求 32 字节 base64 密钥。开发环境未配置时仍可明文，不能用于真实数据。操作审计不保存测量值或问卷正文。
- `/api/community/health-stats` 仅统计当前员工本社区有效同意范围；列表分页与汇总分开。小样本汇总仍有推断风险。
- DeepSeek 助手需登录，默认只用帮助知识。勾选允许后才开放当前身份专用的只读计数/日期工具；工具不接受任意账号/居民/社区 ID，不传姓名、电话、提醒标题、原始测量或问卷答案，也不能写入。**用户输入的消息和历史对话会发送给 DeepSeek**，因此页面提示用户不要输入真实敏感内容。服务端仅允许连接 `api.deepseek.com`，非生产环境另允许回环测试地址；密钥从环境继承，不进网页或仓库。
- 私人报告需本人或有效护理同意下的同社区员工才能上传、下载、预览和审核；家属即使有测量授权、管理员即使能查看聚合，也无法访问原件或候选。原件存私有路径并记录 SHA-256；候选文本与人工审核文本分开。配置字段密钥时文件和文本以 AES-GCM 加密，正式环境强制有密钥；开发无密钥时仍可明文，不得用于真实材料。
- 上传限制 10 MiB、5 页和 PDF/PNG/JPEG/WebP，原件解析使用无业务密钥的独立子进程、有限运行时间；报告内容不作为命令或 URL 执行。每份报告须用户单独勾选云端处理后才排队；**上传报告页面/原生文字可能包含姓名和全部检验内容**，这与网站助手只读工具的最小摘要边界不同。每页发送前重查申请人、会话版本、同意和任务租约。7 分钟租约中断后失败并要求主动重试，最多 3 次，避免崩溃后静默重复发送。
- DeepSeek 转录输出、`quote` 和页码只是待人工核对资料：原生 PDF 文字可用于字符串对齐，图片页文字及引用仍由模型产生。系统没有 PaddleOCR、OCR 边框或已校准置信度；不可声称自动准确识别。确认报告身份后，指标导入仅限显式选择的血压/血糖/体重，且名称、数值、单位和带时区测量时间须由服务端校验。其他检验项目不转成健康指标。
- 已确认报告问答有独立且默认关闭的许可；仅本人和获有效同意的同社区员工可针对单份报告使用，家属和管理员不行。勾选后，问题、历史及人工确认字段会发送 DeepSeek；本次问答不发送原始文件、其他报告和待审草稿。模型只选择限定证据 ID/意图，服务端构造事实文字、原文片段和页码；图片页来源是模型转录，须人工对照原件。会话/报告切换清除许可与对话，服务端在等待模型前后复核权限、会话、版本、文本哈希及原件 SHA-256。每账号 6 次/分钟，最多 100 项/40000 字符上下文和 8 个来源；证据不足或医学咨询不输出诊断与用药建议。问答不写入业务数据，审计只记动作、不保存问题或回答正文。
- 安全响应头、生产 Host 白名单与生产配置校验已实现。生产不自动 `create_all`；Alembic 当前版本在隔离 SQLite 验证。首个迁移版本只适用于新库，不是旧 v0.1 原表的升级路径。

## 真实用户上线前的阻塞项

| 范围 | 尚需完成 |
|---|---|
| 机构与身份 | 正式运营主体、员工开通/离职/找回流程、MFA 设备遗失处理、可信居民身份和纸质证据核验/抽查制度 |
| 数据库与密钥 | PostgreSQL 迁移和备份恢复演练、旧库数据迁移方案、最小权限账号、正式密钥托管/轮换与旧密文重加密 |
| 私人报告生命周期 | 私有目录权限、跨实例持久卷、文件与数据库一致性、留存/删除、备份和恢复、密钥轮换及临时文件清理制度；目前没有完整删除流程 |
| 网络与运行 | HTTPS、反向代理、共享限流（当前限流为单进程内存）、集中审计告警、依赖检查与渗透测试；网页内联脚本使 CSP 仍允许 `unsafe-inline` |
| 隐私与权利 | 告知和同意文本、第三方处理者评估、存储地域/留存期、查阅更正/删除导出流程及备份清理；小样本聚合披露阈值 |
| AI 供应商 | 通用聊天文本、逐份允许的报告提取页面/文字，以及另行允许的已确认报告问答文本/字段会发往 DeepSeek；生产接入需数据传输与用户告知、敏感输入治理、供应商数据留存/删除条款、合同和服务边界审查。模型目录和虚构样本核验不构成真实报告准确率、医学回答质量或合规证明 |
| 人工验收 | 真实机构账号、浏览器与无障碍、运行监控、恢复演练、安全和合规签收；远端 CI/部署均未执行 |

两份问卷只是原创非临床示例；系统不做诊断、处方、心理疾病评级或紧急监护。提醒只有端内待办，不会自动向微信、短信或系统推送。禁止把演示账号、虚构 seed 数据或本地 Docker compose 直接放到公网。
