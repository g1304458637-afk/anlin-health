# 安邻健康 · v0.6 本地开发候选

> 2026-10-23：这是隔离工作树中的可运行开发候选，使用虚构数据验证；尚未部署，也不能直接处理真实居民健康信息。代码许可见 [LICENSE](LICENSE)。

当前入口是居民/家属网页 `/app` 和社区工作台 `/console`，服务端为 FastAPI + SQLAlchemy。居民可管理本人档案、测量、非临床问卷、提醒、社区护理同意与家属授权；工作人员读取和录入健康档案需在本社区且同意有效并已复核；管理员默认只看聚合。`miniapp/` 是封存的历史源码，不再作为当前交付入口。

## 本地运行

建议使用 Python 3.12，先进入 `backend/`：

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements-dev.txt
cp .env.example .env
python scripts/dev_start.py --seed
```

`dev_start.py` 只监听 `127.0.0.1:8000`，并读取 `backend/.env`。本地入口：`/app` 居民/家属门户、`/console` 工作台、`/help` 使用帮助、`/docs` OpenAPI。演示库只含虚构资料；演示账号为 `staff`、`staff2`、`resident`、`family`、`admin`，密码 `DemoPass2026!`。**演示账号和数据不得用于正式环境。**老 v0.1 数据库不能直接套用当前初始迁移，详见部署文档。

## v0.6 已实现的本地流程

- 居民经员工开通账号后，可登录、自建档案，或提交已有线下档案的认领申请。认领提交始终返回统一提示；必须由同社区员工线下核验后批准，提交本身不给予访问权。
- 家属自助注册时没有居民数据权限。家属提供自己的邀请码，由居民选择共享字段和期限；居民可撤回，家属可拒绝。居民也可撤回和重新授予社区护理同意。
- 工作台可查看待复核的纸质同意与认领申请。纸质同意必须由另一位同社区员工复核，待复核或驳回时员工不能访问该档案；证据真实性仍需机构在线下核实。
- 管理员登录工作台后，在“安全与设置 → 员工账号管理”为指定社区开通第二位员工，可查看、停用或启用账号，以安排独立复核；网页不提供管理员创建、角色编辑或密码重置。
- 工作台的 `/api/community/health-stats` 以有效同意过滤社区数据，聚合总数不随列表分页变化。网页支持分页，切换身份或退出时清理旧会话和页面数据。
- 工作台支持分阶段 TOTP 绑定：输入当前密码后生成待确认密钥，使用认证器验证码确认才生效；启用状态下重设和关闭还需验证现有因子。居民手机号、认领电话、待确认和已启用 TOTP 密钥在配置字段密钥后加密存储。
- DeepSeek 助手通过 `/api/assistant/status` 和 `/api/assistant/chat` 回答网站使用及导航问题。默认不查询业务数据；用户明确勾选后，服务端仅提供当前身份的只读数量或日期汇总。助手不能写入、不能指定任意居民 ID，也不通过工具发送姓名、电话、提醒标题、原始测量或问卷答案。**用户主动输入的聊天文本及历史对话会发送给 DeepSeek**；不要输入真实敏感信息。助手不提供诊断、处方或用药建议。模型 `deepseek-flash` 已通过本地继承的凭据在实时目录中确认，密钥未复制进项目文件。
- 本人或有效同意下的本社区员工可上传私人报告（PDF、PNG、JPEG、WebP，最多 10 MiB/5 页）。上传只保留原件；每份报告须另行勾选同意，才将**可能包含姓名和完整检验内容**的页面图像或原生 PDF 文字发送 DeepSeek 生成**待核对草稿**。本人/员工对照原件确认身份和字段，才保存审核结果；仅明确选择且名称、数值、单位与时区时间匹配的血压、血糖、体重可导入健康记录。其他检验项留在报告中。家属即使获测量授权、管理员即使有聚合权限，也不能查看原件或草稿。模型给出的原文引用不是已校准的 OCR 坐标或准确率证据。
- 已确认报告上可点“询问这份报告”，在助手中针对**当前一份报告**提问。报告问答另有默认未勾选的许可；勾选后，问题、历史和该报告的已确认字段会发往 DeepSeek，原始 PDF/图片、其他报告及未核对草稿不进入这次问答。服务端仅按模型选出的受限证据编号构造回答与原文/页码来源卡，不能提供诊断或用药建议；图片来源是模型转录文字，仍须对照原件。切换报告或账号会清空问答和许可。此功能不写入健康记录。

## 验证与限制

当前候选位于 `codex/anlin-web-agent-20261023` 工作树；原始 `main@1ea6061` 未改动。后端自动化、隔离 SQLite 迁移/初始化及网页语法检查在本地运行；最终集成证据以 [QA_REPORT.md](docs/QA_REPORT.md) 为准。DeepSeek 模型目录的实时可用性不等于生产环境验收。

正式使用还需 PostgreSQL 迁移和备份恢复演练、机构账户/MFA 与纸质证据制度、HTTPS、密钥管理与轮换、共享限流、报告保留/删除及备份制度、渗透测试、健康信息合规评审及人工验收。本地预览、合成样本测试或模型调用成功均不能替代这些工作。`assets/report-samples/` 的双页 PDF、首页扫描图与 11 项 golden 仅用于功能测试，不是临床材料或 OCR 准确率标定集。两份问卷是非临床示例，没有疾病预测、诊断或自动推送功能。
